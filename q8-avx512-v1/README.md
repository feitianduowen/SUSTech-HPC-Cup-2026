## 改动

为具备 AVX-512F/BW 且没有 VNNI 的编译目标增加双 block 整数计算路径：合并两个 Q8_0 block 的 32 字节量化数组，用 512 位整数指令完成符号处理及饱和乘加，再拆回两个 8 lane 结果，依次执行原顺序的浮点 FMA。原来的 8 lane 浮点累加器、最终横向求和、FP16 查表、奇数尾块和非 AVX-512/VNNI 路径保持原算法。

对于 x 为零的元素，绝对值乘数本身为零，因此无需额外把 y 清零；负 x 元素按原实现翻转 y 的符号，包含 int8 的 -128 和饱和行为。

补丁见 `q8-avx512-ordered.patch`，修改前后文件哈希见 `patch_manifest.json`。

### 真实动态库微基准

在同节点、同进程中比较部署基线库与新库，单核心绑定 CPU0、内存 node0；每组保留 10 轮交替 AB/BA。流式数据为 256 MiB。以下是每轮基线耗时 / 候选耗时 - 1 的配对中位数，负值代表候选更慢。

| Q8 blocks | 数据驻留方式 | 候选速度变化 |
|---:|---|---:|
| 80 | resident | -7.79% |
| 80 | stream | -12.61% |
| 192 | resident | -6.47% |
| 192 | stream | -14.45% |

这是单核算子微基准，**不是完整模型 PP/TG，也没有正式成绩或自测 Score**。由于本版退化，未继续提交本版完整 PP/TG。

4336681 的摘取版微基准使用 `_cvtsh_ss` 转换 FP16，而源库在 x86 上使用查表，速度对照存在 helper 混杂。其约 -71% 至 -80% 的原始负向结果完整保留，不能直接归因于新内核；本版性能判断采用 4336694 的真实动态库对照。
